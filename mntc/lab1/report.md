# звіт про виконання лабораторної роботи

## 1. постановка задачі

для маршруту від станції до вершини гори говерла побудовано дискретний набір точок по координатах, обчислено кумулятивну відстань і висоту, а потім виконано кубічну інтерполяцію за допомогою сплайнів.

## 2. дані та метод

- використано координати з Open-Elevation API;
- відстані між точками обчислено методом haversine;
- для відрізків побудовано кубічний сплайн з природніми граничними умовами;
- для розв'язання системи застосовано метод прогонки (Thomas algorithm);
- порівняно 10, 15 і 20 вузлів.

## 3. обчислювальна схема

для кожної ділянки інтерполяції використано вираз

S_i(x) = a_i (x - x_i)^3 + b_i (x - x_i)^2 + c_i (x - x_i) + d_i

де коефіцієнти знаходяться з умов неперервності функції, першої та другої похідних, а також природних крайніх умов:

M_0 = M_n = 0

система для внутрішніх значень другої похідної зводиться до тридіагональної матриці й розв'язується методом прогонки.

## 4. результати

після виконання програми отримано такі значення похибки:

- 10 вузлів: RMSE = 13.6708 м, max abs error = 39.5166 м
- 15 вузлів: RMSE = 10.2729 м, max abs error = 33.4001 м
- 20 вузлів: RMSE = 7.3043 м, max abs error = 33.4724 м

## 5. висновки

- збільшення кількості вузлів покращує апроксимацію;
- при 20 вузлах сплайн дає найменшу RMSE;
- при цьому графік залишається гладким і стабільним навіть на складних ділянках профілю;
- кубічний сплайн ефективний для апроксимації рельєфу маршруту.
